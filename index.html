RESPALDO DE DATOS

El respaldo genera un archivo JSON con el catálogo de personal, la bitácora completa, las sesiones activas y la configuración de la aplicación. Guárdalo en un lugar seguro y utilízalo para restaurar la información en caso de cambiar de computadora o de navegador. Los datos se guardan y se sincronizan en tiempo real a través de Supabase entre todas las computadoras y celulares que abran esta aplicación. El navegador conserva además una copia local (caché) para seguir mostrando información aunque se pierda la conexión a internet.

CONEXIÓN CON SUPABASE

Pega aquí la URL y la clave pública ("anon public") de tu proyecto de Supabase. Las encuentras en Supabase → ícono de engrane "Project Settings" → "API". Estos datos se guardan solo en este navegador (no requieren editar el archivo HTML) y se usan para conectar esta computadora o celular a tu base de datos compartida. La clave "anon" es pública por diseño — no es una contraseña.
